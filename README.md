# Caesar Cipher - Task 01

## Prodigy InfoTech Cyber Security Internship

### Objective
Create a Python program that can encrypt and decrypt text using the Caesar Cipher algorithm.

### Features
- Encrypt text
- Decrypt text
- User-defined shift value
- Supports uppercase and lowercase letters
- Preserves spaces and special characters

### Technologies Used
- Python
- Google Colab

### How It Works
The Caesar Cipher shifts each letter in a message by a specified number of positions in the alphabet. For encryption, letters are shifted forward by the given shift value. For decryption, letters are shifted backward using the same shift value.

### How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. Choose Encryption or Decryption.
4. Enter the message.
5. Enter the shift value.
6. View the result.
